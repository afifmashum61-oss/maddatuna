# maddatuna - Media Pembelajaran Bahasa Arab Kelas 7 MTs (Kurikulum 2025)

Aplikasi Web Interaktif Media Pembelajaran Bahasa Arab Kelas 7 Madrasah Tsanawiyah (MTs) berbasis **Buku Siswa Kementerian Agama RI Tahun 2025**.

![Bahasa Arab Kelas 7](https://img.shields.io/badge/Kurikulum-Kemenag%202025-004d40?style=for-the-badge)
![Tema UI](https://img.shields.io/badge/Theme-Bottle%20Green%20%26%20Gold-d4af37?style=for-the-badge)

## 🌟 Fitur Utama

- 🎨 **Desain UI Modern (Hijau Botol & Putih)**: Menggunakan kombinasi warna Hijau Botol (`#004D40`), Putih, dan aksen Emas (`#D4AF37`) yang elegan, responsif untuk HP dan PC.
- 🗂️ **30 Mufrodat Interaktif (Kartu Flip 3D)** per Bab: 
  - Kosakata Arab berharakat + Latin + Terjemahan Indonesia.
  - Pelafalan Audio **Text-to-Speech (`ar-SA`)**.
  - Contoh Kalimat Sederhana (*Jumlah Mufidah*) di balik setiap kartu.
- 💬 **Hiwar (Percakapan Panjang)**: Dialog kaya antara 2 karakter dengan fitur pemutar suara otomatis per dialog dan sakelar terjemahan.
- 📖 **Maharah Qira'ah (Membaca)**: Teks bacaan naratif lengkap dengan audio pemutaran teks dan soal pemahaman (*Fahmul Maqru'*).
- ✍️ **Maharah Kitabah & Qawa'id (Tata Bahasa & Menulis)**: Penjelasan tata bahasa visual dan **Latihan Menyusun Kata (Tarkib)** interaktif.
- 📝 **Soal Latihan & Evaluasi Kuis**: Kuis interaktif per bab dengan perhitungan skor langsung, pembahasan jawaban, dan **Sertifikat Kelulusan Digital** yang dapat dicetak/disimpan ke PDF.

## 📚 Cakupan 6 Bab Pembelajaran

1. **Bab 1**: التَّعَارُفُ (Perkenalan / At-Ta'aruf)
2. **Bab 2**: الْمَرَافِقُ الْمَدْرَسِيَّةُ (Fasilitas Sekolah / Al-Marafiq Al-Madrasiyyah)
3. **Bab 3**: الأَدَوَاتُ الْمَدْرَسِيَّةُ (Peralatan Sekolah / Al-Adawat Al-Madrasiyyah)
4. **Bab 4**: الْعُنْوَانُ (Alamat / Al-'Unwan)
5. **Bab 5**: الْبَيْتُ (Rumah / Al-Bait)
6. **Bab 6**: مِنْ يَوْمِيَّاتِ الأُسْرَةِ (Kegiatan Sehari-hari / Min Yaumiyyatil Usrah)

## 🚀 Cara Menjalankan

Aplikasi ini dibuat sebagai Web App murni (HTML5, Tailwind CSS, JavaScript ES6) yang dapat langsung dibuka tanpa perlu server khusus:

1. Clone repositori ini:
   ```bash
   git clone https://github.com/afifmashum61-oss/maddatuna.git
   ```
2. Buka file `index.html` langsung pada Google Chrome, Edge, atau browser pilihan Anda.
